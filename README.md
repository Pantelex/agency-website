# Agency Website

A modern and responsive agency website built with HTML, CSS, and JavaScript.

## 🚀 Live Demo

[View Live Website](https://pantelex.github.io/agency-website/)

## 📌 About The Project

This project is a modern agency website designed to present services, projects, and company information in a clean and professional way.

The website focuses on responsive design, modern UI, clear navigation, and a user-friendly experience across desktop, tablet, and mobile devices.

## 🛠️ Technologies

* CSS3
* JavaScript
* Responsive Web Design

## ✨ Features

* Responsive design
* Modern user interface
* Mobile-friendly navigation
* Interactive JavaScript elements

* Project/portfolio section
* Contact section
* Smooth and user-friendly layout
